Pulse Fiber

Customer Segmentation & Revenue Forecasting

Challenge

Pulse Fiber needed better visibility into customer behavior, churn risk, and future revenue trends. Traditional reporting could describe what had already happened but provided limited insight into customer segments and emerging risks.

Solution

Developed a Python-based analytics workflow that segmented customers based on behavioral and account characteristics, identified indicators associated with churn, and produced revenue forecasts for planning and management analysis.

The analysis emphasized transparent methods that could be explained to operational and leadership teams rather than relying on an opaque black-box model.

Capabilities

  • Python
  • Customer Segmentation
  • Churn Analytics
  • Revenue Forecasting
  • Data Preparation
  • Business Intelligence

Business Value

Provided clearer customer segmentation, better visibility into potential churn risk, and a structured approach for evaluating future revenue performance.

City of Loveland

Automated SCADA Analytics Pipeline

Challenge

Operational SCADA data from nine electrical substations needed to be transformed into consistent, usable information for reporting and operational analysis. Manual processing would make recurring reporting difficult to maintain and increase the risk of inconsistent data.

Solution

Developed an automated analytics pipeline that processes incoming SCADA data using Python, applies validation and transformation rules, and produces standardized datasets for Power BI Report Server reporting.

The workflow was designed to automate recurring data preparation and create a consistent foundation for operational analytics.

Pipeline

  1. SCADA
  2. Python ETL
  3. Data Validation
  4. Structured Dataset
  5. Power BI Report Server

Capabilities

  • SCADA Analytics
  • Python
  • ETL Development
  • Data Validation
  • Automation
  • Power BI Report Server
  • Utility Operations Analytics

Business Value

Automated recurring SCADA data processing, reduced manual reporting effort, standardized the underlying data, and improved access to operational information.

Stampd Social

Social Travel Logging & Recommendation Platform

Project Focus

Build a recommendation workflow that could use travel and social data to generate more relevant suggestions within a social travel platform.

Solution

Built a 30-feature recommendation system using PostgreSQL travel and social data with CatBoost ranking models. Developed a FastAPI inference microservice with versioned model deployment.

Integrated the serving layer into an AWS ECS and Terraform stack with CI/CD, container orchestration, and scalable runtime configuration.

Capabilities

  • PostgreSQL
  • CatBoost Ranking
  • FastAPI
  • Model Deployment
  • AWS ECS
  • Terraform
  • CI/CD

Business Value

Established a deployable recommendation platform that connects model ranking to a containerized runtime and repeatable infrastructure.
